# Bootstrap Projects (HTML + CSS only)

Each folder has three things:
- `index.html` – the page (Bootstrap classes do most of the layout)
- `css/style.css` – my own colours and small changes to Bootstrap
- `img/` – the pictures

Open `index.html` in a browser. You need internet, because Bootstrap is loaded from a CDN.

## restaurant/ – Jiko Ember (Grid System)
- Navbar: name on the left, links on the right (`ms-auto`)
- Hero: background image with a centred heading and button
- Menu: 3 cards in a grid (`row` + `col-md-4`)
- About Us: two columns (`col-md-6` + `col-md-6`)
- Contact: form with name, email, message and a submit button
- Footer: copyright and social icons

## Responsive
Grids show 3 columns on bigger screens and 1 column on phones.
On phones the navbar puts the name on top and the links underneath.
